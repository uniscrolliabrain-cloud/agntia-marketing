- `docs/research/`, `docs/release/` y otras fuentes originales.

Migración futura segura: inventario completo, copia a `docs/prep/`, reescritura y comprobación de enlaces, actualización del manifiesto, verificación y solo entonces eliminación de rutas antiguas en un commit separado. Mientras tanto la fuente original permanece accesible y se considera baseline congelable por SHA.
